Hacerlo a mano (Programación de Consultas): clic para ver los pasos
  1. Entra a Campus Evolution: Menú Principal › Herramientas de Informes › Consultas › Programación de Consultas.
  2. Buscar un Valor → Buscar → clic en el ID Control Ejecución AC_ALUMNOS_GB. (Si no existe: Añadir un Valor → AC_ALUMNOS_GB → Añadir → Consulta AC_ALUMNOS_GB.)
  3. Escribe los 4 valores de la fila de abajo (clic en cada uno para copiarlo) → Acep. Para la siguiente combinación usa Actualizar Parámetros.
  4. Ejec → Formato XLS → Acep.
  5. Monitor Procesos → Actualizar hasta "Correcto / Enviado" → Detalles → Registro/Rastreo → clic en AC_ALUMNOS_GB-NNNNNNN.xls.
  6. Arrastra los archivos descargados al paso 2. No hace falta renombrarlos: cada uno se reconoce por su contenido.

Evita el botón Ver Resultado de Consulta: ese Excel puede venir cortado. Los archivos de Programación de Consultas se marcan como completo.
